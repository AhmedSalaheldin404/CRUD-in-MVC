🇬🇧 CRUD Operations Page – ASP.NET Core MVC
🧾 Overview

This project demonstrates a complete implementation of CRUD (Create, Read, Update, Delete) operations using ASP.NET Core MVC.
It provides a clean and structured way to manage data through a web interface, following the MVC architectural pattern.

⚙️ Tech Stack

ASP.NET Core MVC (.NET 8)

Entity Framework Core

SQL Server

Bootstrap 5 for responsive UI

LINQ for data queries

💡 Features

➕ Create: Add new records through a dynamic form with validation.

📄 Read: Display a list of all entries with sorting and filtering options.

✏️ Update: Edit existing records using pre-filled forms.

❌ Delete: Remove records safely with confirmation prompts.

🔄 Database Integration: Connected to SQL Server via Entity Framework for data persistence.

🎨 User-Friendly UI: Built with Bootstrap for a simple and responsive design.

🧠 Concept

The project follows the Model–View–Controller (MVC) design pattern:

Model: Defines the data structure and database interactions.

View: Renders clean and dynamic HTML pages for user interaction.

Controller: Handles HTTP requests, business logic, and communication between Model and View.

🎯 Goal

To provide a simple yet powerful example of how to implement CRUD functionality in ASP.NET Core MVC, suitable for beginners and scalable for production projects.
